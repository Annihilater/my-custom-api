原始订单执行报告（需用户自行解码）

此函数用于接收原始的订单执行报告。报告内容包括但不限于订单状态、执行细节等。
由于报告是原始形式，因此需要用户自行解码以获取具体信息。

:type session_id: int
:param session_id: 会话ID。
:type platform_type: int
:param platform_type: 交易网关平台类型，用于区分回报类型。
:type report: void
:param report: 报告数据的指针，具体内容依赖于报告类型，需用户自行解码。
